# Sales Performance Dashboard

An interactive Excel dashboard built from a month of raw sales data — covering 
data cleaning, pivot tables, KPI tracking, and slicer-driven filtering across 
city, product, region, and salesperson.

## Overview

Delivered a self-service view into a month of sales performance, as measured by 
real-time KPI tracking (₹3,05,000 total sales, ₹50,833 average) sliceable by 
city, product, region, and salesperson, by cleaning raw data, building pivot 
tables, and designing an interactive Excel dashboard with slicers.

## Key Insights

- **Mumbai led all cities** with ₹1,39,000 in sales, more than double Delhi's ₹61,000
- **Phone outsold Laptop** — ₹1,73,000 vs. ₹1,32,000
- **Top performer:** Ravi (₹72,000) vs. lowest, Meera (₹20,000) — a 3.6x spread across the sales team

## Workbook Structure

The workbook (`Sales_Performance_Dashboard.xlsx`) contains four sheets:

| Sheet | Description |
|---|---|
| `Raw_Data` | Original, unprocessed sales data |
| `Clean_Data` | Cleaned and transformed dataset |
| `Pivots` | Pivot tables powering the dashboard visuals |
| `Dashboard` | Final interactive dashboard with KPIs, charts, and slicers |

## Process

1. **Data Cleaning** — imported raw sales data, handled inconsistencies, and standardized formatting
2. **Pivot Tables** — built pivot tables to aggregate sales by city, product, region, salesperson, and date
3. **KPI Cards** — calculated total and average sales as headline metrics
4. **Visualization** — created bar charts for city/product/salesperson performance and a monthly trend line
5. **Interactivity** — added slicers (City, Product, Region, Salesperson, Date) so the dashboard filters dynamically without touching the underlying data
